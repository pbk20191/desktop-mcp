# MCP Swift SDK Migration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace desktop-mcp's hand-rolled MCP protocol layer with `modelcontextprotocol/swift-sdk` 0.12.1 while keeping the NIO socket layer, the tools, the launchd flow and the `connect` bridge.

**Architecture:** A `ToolRegistry` actor keeps the tool table and builds an SDK `Server` on demand, one per stdio process or per HTTP request. The SDK's `StatelessHTTPServerTransport` is called from inside the existing `HTTPApp` after its middleware; `NIOHTTPServer` is untouched. The legacy SSE transport, `JSONRPC.swift`, `JSONValue.swift` and the `MCPServer`/`MCPSession` actors are deleted.

**Tech Stack:** Swift 6 (tools 6.1, Xcode 16.4), SwiftPM, `MCP` product of `mcp-swift-sdk` 0.12.1, SwiftNIO + NIOTransportServices (unchanged), XCTest.

**Spec:** `docs/superpowers/specs/2026-10-19-mcp-swift-sdk-migration-design.md`

## Global Constraints

- `// swift-tools-version:6.1`; `swiftLanguageModes: [.v6]`; `platforms: [.macOS(.v13)]` unchanged.
- SDK pin: `.package(url: "https://github.com/modelcontextprotocol/swift-sdk.git", from: "0.12.1")`, product `MCP`.
- `swift-collections` cap `"1.1.0"..<"1.3.0"` stays.
- Every build and test run in this plan uses `DEVELOPER_DIR=/Applications/Xcode-16.4.app/Contents/Developer` and `ANONYMIZED_TELEMETRY=false HOME=$(mktemp -d)` for tests.
- No `@unchecked Sendable` added. No new runtime dependencies.
- **No commits.** The repository owner commits; tasks end at "tests pass". (Owner's standing instruction; overrides the commit steps this plan format normally has.)
- The hand-rolled protocol code is deleted by the end, not left alongside.
- Behaviour on the wire that must not change: `tools/list` output equals `spec/tools.json`; a tool error is a result with `isError: true` and text `Error executing tool <name>: <message>`; a cancelled call is a result with `isError: true` and text `Cancelled.`; `resources/list`, `resources/templates/list`, `prompts/list` return empty lists.

## Review Focus

1. A tool argument string that starts with `data:` (for example `Scrape` with `url: "data:text/html,..."`). `MCP.Value` decodes such strings as `.data`, so `ToolArguments.string` must still return the original text, not `nil` or a type error. Test in Task 2.
2. Two HTTP clients sending the same JSON-RPC id concurrently. Each must get its own response, never a hang. Test in Task 3.
3. A `tools/call` whose `arguments` is not an object (`"arguments": "nope"`). The client must get a JSON-RPC error, not a crash or a hung request. Test in Task 2.
4. Request ids beyond 2^53 (`9007199254740993`). The response must echo the id exactly. Test in Task 2.
5. A Launch Agent plist written by an older version with `--transport sse`. `serve` must start as streamable-http with a warning, not crash-loop under `KeepAlive`. Test in Task 4.

`StartedServer.shutdown()` cancels every task in the in-flight map, then `await server.stop()`.

- [ ] **Step 6: Implement `StdioServer.swift`**
